# 给大模型装一个"物理小脑"
## 确定性 τ 谱校验如何让事实型错误可收敛——一个可证伪的工程案例

> **一句话摘要**：大模型会"流畅地说错"，根因不是它不够聪明，而是它只向"像不像人话"收敛、不向"是否符合可复算事实"收敛。我们给它外挂一个**确定性、可复算、不依赖大模型本身**的"物理小脑"（System-1），在"事实校验方向"上补一个原本缺失的纠错耗散通道，并把"打回重写"真正闭环成反馈回路。首轮受控实验（M0）观察到：**开环时错误四轮原地不动（1.00→1.00），闭环时随反馈轮下降（1.00→0.50），而故意喂错锚点会在模型不确定处把答案带偏**——增益、无效、反作用都在实验前写死的对照里被一一观测到。这只是机制可行性的方向性证据，不是性能宣告，更不是"已消灭幻觉"；本文如实给出它的六个失效条件与复现路径。其后我们在同一冻结基准上换四个开源本地模型做了复现实验（M1）：开环臂依旧四轮不降，闭环臂在三个模型上末轮归零、最弱的 7B 也降到 0.25，反馈收敛时间的置信区间下界均为正——机制由此从"首轮方向性支持【E0】"升为"跨基座有经验支持【E1】"，但它仍是条件性机制而非普适定理，三条复现边界在 §6.4 一并给出。

**关键词**：大模型事实性、System-1/System-2、确定性校验、非厄米耗散、弛豫时间 τ、可证伪工程、人在回路回验

## 1. 问题：为什么"让它更聪明、更会自查"治不了事实型错误

### 1.1 流畅与事实，是两个不同的收敛方向

当代大模型在"语言是否通顺、自洽、像人写的"这件事上已经极强。但一个句子可以同时做到**内部极其自洽、外部与事实不符**。这不是偶然 bug，而是训练目标的结构性结果：模型被优化去逼近"高概率语言数据流形"，而不是"外部可复算事实"。

借用 IGT 的非厄米动力学语言（严格表述见 P43 §1.2，本文只作直觉转译）：一个有耗散的系统会把偏离"吸引子"的扰动拉回来。大模型的"耗散"把隐状态使劲拉向**语言流形**（像不像人话），却在**外部事实校验方向**上几乎没有拉力。于是它可以一边高度收敛到"流畅"，一边在"对错"维度上自由漂移。语言流畅度类指标（困惑度、流畅度评分）天然测不到这条正交方向，这也是"模型自评/自查"往往不可靠的深层原因。

### 1.2 三类常见做法，各自缺了什么

面对事实型错误，工程上最常见的三类手段是：**检索增强（RAG）**、**加校验提示词（让模型自我检查/扮演审稿人）**、**多模型投票（self-consistency / ensemble）**。它们都有用，但都没有补上"事实方向的确定性收敛"这一环：

- **RAG** 解决的是"模型不知道"——把外部资料塞进上下文。但它不保证模型**采信**资料：资料与模型先验冲突时模型仍可能无视或曲解；检索到错误资料时同样会被流畅地采纳。它提供了"原料"，没有提供"违背可复算事实就必须被拉回"的约束力。
- **校验提示词 / 模型自查** 本质是让同一个概率系统再采样一次。事实方向的耗散依然缺失，第二次"自查"仍在语言流形上打转，不构成独立于模型的判据。
- **多模型投票** 用多个同源模型的多数票压制随机误差，但**系统性偏差会被投票放大**：当多个模型共享同一种错误直觉时，多数票反而更自信地错。投票的判据仍然是"模型们怎么说"，不是"可复算的事实是多少"。

这三类方法的共同缺口是：**缺一个独立于大模型、确定性、可复算、并且能把错误真正"拉回来"的外部约束回路。** 这正是"物理小脑"要补的位置。

### 1.3 我们要的不是"更聪明的模型"，而是"错误可收敛的结构"

请注意目标的克制表述：我们不试图把某个开源小模型调教成 AGI，也不承诺消除一切幻觉。我们只问一个可被证伪的工程问题——

> **对于"存在可复算物理/事实锚"的那一类问题，能否用一个确定性外部算子，让大模型的事实型错误随着反馈轮次而收敛，并且这种收敛有明确的成立条件与失效条件？**

这是一个"结构是否成立"的可行性问题，而不是"准确率刷到多少"的性能问题。

## 2. 机制直觉：纠错 = 给"缺耗散的方向"补一个耗散通道

这一节给最小物理直觉。严格推导（能量衰减、Gronwall 不等式、"2 倍因子"来源）在 P43 §3，本文不重复证明，只讲清图像。

### 2.1 弛豫时间 τ：一个系统"多快回到稳态"

IGT 用非厄米生成元 **L = H − iΓ**（H 为厄米的"振荡/相干"部分，Γ 正定的"耗散/回归"部分）描述回归动力学，本征值 λ_n = ω_n − iγ_n，模态按 e^{−iωt}·e^{−γt} 演化，**弛豫时间 τ_n = 1/γ_n**（注意是 1/γ 不是 1/ω：ω 管振荡快慢，γ 管回归快慢，二者不可混）。

- γ 越大，τ 越小，偏离稳态后回来得越快（健康、稳定）；
- γ → 0 时 τ → ∞，这个方向"拉不回来"（逆元不闭合，见 P41）；
- γ 转负时模态不再衰减反而指数放大（失稳）。

> 符号约定（避免工程实现混淆）：物理术语中 **γ>0 是衰减/回归、γ<0 是增长/失稳**；代码里的"增长率 g"是其相反数 g = −γ，故代码判"出现增长模"写为 ∃(g>ε_c)。两套符号在模块接口处显式换算，本文正文统一用物理符号 γ。
>
> **适用域注（不动点型稳态与自持节律的分界）**：上面"γ→0 即拉不回、γ 转负即失稳"的判据针对**不动点型稳态**。对自持振荡（极限环，例如呼吸、心率这类节律信号），系统恒有一个沿轨道方向的中性相位模 γ∥=0（Goldstone 模），它不代表失稳或"逆元不闭合"；此时稳定性要看**横向扰动**的 Floquet 乘子是否落在单位圆内，而不能要求所有模态 Γ 正定（引自 P44）。本文实验对象是不动点型失稳（增长模），故采用全模 γ 判据。

### 2.2 幻觉的谱图像：一个方向强拉、另一个方向不拉

把模型的连续表示空间粗略分解为两个正交子空间（P43 §2）：

- **语言连贯方向 L**：自洽、通顺、像人话——这个方向耗散很强（Γ^L ≫ 0）；
- **外部事实校验方向 F**：输出要与可复算锚一致——幻觉状态下这个方向**耗散缺秩**（Γ^F ≈ 0）。

于是错误在 L 方向被迅速"抛光"得流畅自然，在 F 方向却几乎不衰减。这给出一个可计算的代理量"幻觉易感性" H_hall = λ_max^L − λ_min^F（P43 §2.2），但它必须由**真实隐状态序列**估计，属待验证项【E2：须真实隐状态序列】（截至本文，开源模型逐 token 词嵌入与逐层隐状态张量的**取数通路已验证可行**，但 H_hall 的谱估计尚未完成，故 H7.2 仍标【E2】），云端黑盒取不到隐状态、只能做行为层对照（见 §7.4）。

### 2.3 小脑做的事：在 F 方向注入"正定耗散"

既然缺的是 F 方向的耗散，那就由一个**确定性小脑**在同一方向补上一块"锚点耗散" Γ_A：

$$\Gamma_{eff}^{F}=\Gamma_{S}^{F}+\Gamma_{A}^{F}$$

（S 指模型自身 system，A 指锚点 anchor）。当锚点在事实方向上确有"正定投影"时，原本 Γ_S^F≈0、拉不回来的错误，重新获得有限 τ、开始指数收敛。这就是**锚点增广不等式（工作假说 H7.3）的直觉**。

> **漂移—扩散图像（引自 P43 §7.7）**：更完整的图像是**漂移—扩散分解** `dx = −Γx dt + √(2D) dW`：**确定性小脑＝漂移项 −Γx**（沿主导耗散模最速弛豫、给路径锚 F_det）、**大模型＝扩散项**（有限温度随机探索、不保证下山）、**用户＝目标/边界条件**（选吸引子盆、承载价值，是约束不是力）。漂移与扩散的竞合用**净收敛数**判：`Pe_F = Γ_S(F)·L_F / D_F` —— Pe_F > 1 才净收敛（A 臂）、趋近 0 为纯扩散不降（B 开环臂）、错锚即漂移反向（C/D 臂）。**Pe_F 临界值 1 是理论值，工程门限待标定**（勿读作实测阈值）。
>
> 另须区分**双锚（正交、非平级）**：**目标锚**（用户/定"去哪"，承载意图与价值）与**路径锚**（小脑 F_det/定"怎么到、能否到、代价多少"，属谱可复算）**正交**；路径锚对目标锚有告知义务、**无价值否决权**（"顾问不是刹车"）。

必须立刻强调三条，否则就会误读成"包治百病"：

1. 它是**条件性**的，不是普适上确界——IGT 明确不主张普适的效率或收敛上确界，只陈述在下列条件下成立的条件性机制。锚点方向错、回路没闭合、证据弱到淹没在噪声里……任一条件不满足都无效甚至反增错，六个失效条件在 §7.3 逐条列出。
2. "打回重写"必须**真的进入下一次生成**（闭环）。只把锚点和模型答案并列展示、却不把偏差反馈回去，等于没接上耗散，退化为两个互不相干的系统并排。
3. 锚点本身必须是 **core 纯函数可复算量**、错误率远低于模型、并带自检复算哈希——绝不能把"模型自己说的话"或未经验证的工程估计当锚点回灌，否则就是循环自证。

### 2.4 为什么"回验打回"在数学上不是玄学：它和物理弛豫同构

反馈纠错在离散轮次上进行。P43 §4（H7.4，结构性命题【T】）指出：第 k 轮反馈后的残余错误率服从

$$d_{fb}(k)=1-e^{-2k/\tau_{fb}}$$

它与物理系统的逆元破缺度 d_n(t)=1−e^{−2t/τ_n}（P41）**严格同构**【T，结构命题】：连续时间 t 换成离散反馈轮 k，物理弛豫时间 τ_n 换成"以轮为单位的反馈收敛时间 τ_fb"。

但这里必须把两层不同性质的断言分开，以免被读成"物理定理已经证明反馈纠错一定有效"：

- **数学同构【T】证明的只是一个条件结构**——*若*闭环反馈确实等效于在事实方向 F 上注入了正定耗散，*则*残余错误必然按 d_fb(k) 的形状指数收敛，收敛快慢由 τ_fb 决定；
- **而"本工程的闭环反馈是否真的等效于正定耗散"并不是定理保证的**，它是一个经验命题：M0 给出首轮方向性支持【E0】，M1 四模型复现后升为【E1】（见 §6.4）；但数学同构【T】与经验有效【E1】的分界不变——不可把同构读作"已用物理定理证明反馈纠错有效"（P43 §4.2）。

换句话说，物理定理负责回答"前提成立时收敛曲线该长什么样"，实验负责回答"这个前提在大模型回路上到底成不成立"，两者不能互相当作证据。τ_fb 的工程含义是证据累积到裁决翻转平均需要几轮；其数值 M0 只给数量级、M1 给出带置信区间的数量级估计（见 §6.4），因每档拟合点仅 3–4 个，指数函数形状本身尚未被严格分辨。

## 3. 工程架构：确定性小脑（System-1）× 大模型（System-2）

### 3.1 分工原则：确定性归小脑，不确定性归大模型

IGT 在受控实验中得到一条清晰的分界（它由一次"反直觉"的实测确立）：当判据是确定的、标签与真值共用同一判据时，"数值→符号方向""无噪存在性判断""谱计算"都会退化成**平凡的确定性查表/计算**，没有任何"认知"可言；真正需要"认知负担"的，只有噪声地板附近"这个微弱正模到底是真信号还是随机涨落"这种**不确定性下的证据权衡**。

由此确立分工：

- **System-1（确定性小脑，core 纯函数）**：时序→谱（EDMD）、数值→符号方向、无噪存在性判断、中心化 z、变点分段等一切**输入确定则输出唯一、可复算、可哈希**的部分；
- **System-2（大模型）**：噪声附近的显著性裁决、语义理解、把现实问题映射到可校验量、以及价值/意图/创造等无物理锚的部分。

### 3.2 三端铁律：把"确定性"和"模型/网络"物理隔离

工程上拆成三个职责严格不同的部分：

```text
输入时序 / 传感器 / 数据
        │
        ▼
┌─────────────────────────────────────────────┐
│ core（纯计算，零文件系统/网络/系统调用）      │  ← System-1 确定性小脑
│  EDMD 提谱 → L=H−iΓ → γ/τ/复谱指纹/变点       │     同一份输入必得到同一份输出，可哈希、可复算
└─────────────────────────────────────────────┘
        │  AnchorEnvelope（结构化锚包，带量纲/准入档/自检哈希）
        ▼
┌─────────────────────────────────────────────┐
│ agent（本地、单用户、可断网自治）             │  ← 采集、滑窗、bootstrap 噪声地板、组 prompt、收发模型
└─────────────────────────────────────────────┘
        │  只经"冻结的结构化契约"对话，不传权重、不把网络请求塞进 core
        ▼
┌─────────────────────────────────────────────┐
│ System-2 大模型（本地开源 或 云端黑盒）        │  ← 输出结构化可验量 ClaimForCheck
└─────────────────────────────────────────────┘
        │  ClaimForCheck
        ▼
   L2 接缝层：只做"归一 + 比对 + 裁决"，不做自由语义映射 → Verdict（放行/带方向打回/升级人审）
```

关键设计选择：**让大模型先输出结构化可验量**（observable 观测了哪个量 / value 数值 / unit 单位），L2 接缝层**只做归一化与比对**；"把一段自由文本自动翻译成物理量"这一步暂不做。这把最不可控的"语义→数字"约束成了模型必须显式声明的结构化字段，使比对可复算。

### 3.3 五条耦合通道 C1–C5（C2、C5 是主干通道）

大模型只通过五条定义清楚的通道与小脑耦合（P43 §5，构造性【T】）：

| 通道 | 作用 | 通道定位 |
|---|---|---|
| **C1 前置分段/显著性** | 时序一进来先做准平稳分段、事件边界/变点检测，给后续"时间骨架"，无需唤醒大模型，廉价 | 增效层 |
| **C2 物理事实闸门** | 仅当问题是"事实型且有可复算量"时触发，输出 {τ, γ, ω, 稳态色, 谱指纹} 封装成锚向量，带量纲、数据准入档与自检哈希 | **主干通道（承载 H7.3 正定注入）** |
| **C3 按需唤醒门控** | 只在"新奇 / 失稳 / 越界"三种情况烧大模型算力，稳态常行走轻通道直出 | 增效层 |
| **C4 τ 谱短时外推** | 定常段内做动力学预报（不是贝叶斯预测加工；IGT 不引入变分自由能公设），切换段重置不跨段 | 增效层 |
| **C5 事后回验逆元** | 结论投影到公共校验空间→小脑同刻复算→比距离 δ_F 与容差 ε_c→超界则**带偏离方向打回、k+1**→达上限升级人审 | **主干通道（承载 H7.4 闭环反馈）** |

配套三份（加参数档共四份）**冻结契约**：`AnchorEnvelope`（小脑→模型）、`ClaimForCheck`（模型→小脑，含 claim_type 四分类）、`Verdict`（小脑→模型/人）、`PersonalParamProfile`（ε_c/k_max/τ_fb 只由个人纵向数据离线标定、运行时只读、冷启动不写死）。每个字段强制标注身份：【定理值 / 工作假说 / 工程假设·待标定】，三类不许混写。

## 4. 与 RAG / 校验提示词 / 多模型投票的本质区别

这是本文最需要对外讲清的一点。差别不在"有没有外部信息"，而在**判据是否独立、是否可复算、是否真闭环、增益是否有可陈述的成立与失效条件**。

| 维度 | RAG | 校验提示词/自查 | 多模型投票 | **本方案：确定性小脑闭环** |
|---|---|---|---|---|
| 判据来源 | 检索到的文本（可能错） | 同一模型再采样 | 多个同源模型 | **core 纯函数现算的可复算量 + 自检哈希** |
| 是否独立于模型 | 弱（仍靠模型采信） | 否 | 否（同源偏差共振） | **是（确定性算子，错误率须远低于模型）** |
| 是否闭环回灌 | 否（只在前置供料） | 弱（再生成无确定方向） | 否（一次性聚合） | **是（带偏离方向打回、真进下一次生成）** |
| 增益有无机制解释 | 工程经验 | 工程经验 | 工程经验 | **有：H7.3 在事实方向补正定耗散（条件性）** |
| 失效能否预先列举 | 难 | 难 | 难 | **能，六个失效条件实验前写死（§7.3）** |
| 能否被一个实验证伪 | 不易 | 不易 | 不易 | **能，六条负面对照预埋（§5）** |

一句话：**RAG 给的是"知识"，小脑给的是"约束 + 回路"。** 前者让模型"有得参考"，后者让模型"在可复算事实上偏离时被确定性地拉回，且拉不拉得动、什么情况下反而被带偏，都事先说清楚、事后可检验。"

## 5. 可证伪性：实验开始前就写死的六条负面对照

一个机制"看起来有效"很容易——事后总能编出解释。我们采用相反的做法：**在看到结果之前**，先写死六条对照，每条都规定"机制成立应该看到什么、如果看到相反现象就证伪"（P43 §8.1）。

| 对照 | 设计 | 机制成立应观测到 | 若观测到相反 |
|---|---|---|---|
| **(i) A 闭环臂** | 正锚 + 逐轮把偏差打回重生成 | 事实型错误随轮 k 按 d_fb 下降 | 什么都降错 → 证伪 |
| **(ii) B 开环臂** | 字节级相同的锚，但**不回灌**（只并列展示） | 错误率原地不降 | 开环也降 → 证伪（说明只是"多问几遍就好"） |
| **(iii) C 错锚臂** | 锚形态合规、但方向被故意篡改 | 模型不确定的弱信号区错误反升 | 错锚毫无作用 → 因果方向存疑 |
| **(iv) D 纯创造臂** | 无物理锚的价值/创造类问题 | 无显著降错增益（本就不该有） | 纯创造也"降错" → 证伪（越界） |
| **(v) 多模态真融合 vs 硬拼（多模态复现实验 M2）** | 同源信号 vs 无关画面 | 真融合出现显著跨通道耦合、硬拼被拒 | 硬拼也"融合" → 共嵌入判据失效（M2 已**通过预注册判据**：跨模态耦合成立、错配被拒；**但仅限于「基线感知识别＋耦合准入」层面，不构成 H7.3 升档证据——H7.3 的主证据来自语义/文本通道、已【E1】，多模态命题 H9.1 仍【E2】**；且仅在**单一基座 Qwen3-VL-8B** 上验证、不构成跨模型族复现） |
| **(vi) 主导耗散路径相关（预埋检验，尚在进行）** | 独立由谱估计主导模弛豫时间 τ_dom，与反馈收敛时间 τ_fb 对照 | τ_dom 与 τ_fb **同量级**且跨模型相关 | 二者系统无关 → 「物理最优耗散路径」的物理解释降级为纯语义约束（**当前状态：相关性方向初步支持、同量级尚待验证，故列为半完成的预埋检验**） |

**判定铁律：任一必要对照被违反，即判机制证伪，回到理论层面重新构造，禁止用"大模型玄学"事后圆场。** 增益只允许出现在"锚点在事实方向有正定投影 + 闭环反馈 + 事实型问题"这个精确组合里。这种"先把自己怎么才算错写清楚"的纪律，是本案例区别于一般 prompt 经验帖的核心。

## 6. 首轮实验 M0 看到了什么（证据档【E0】，请连同限制一起读）

### 6.1 实验设置（刻意收窄，先问"机制在不在"）

- **任务域**：系统失稳窄任务（给一段合成的多通道时序，判断其中是否存在"增长模"这一事实型结论）；
- **证据锚形态**：中心化显著性三元组 {γ, 符号方向, z = |γ−b|/ε_c}，其中 b 是 EDMD 的恒定负偏置（中心化扣除），ε_c 是只从输入噪声客观估计的噪声地板（**严禁调整 ε_c 去凑目标错误率**，难度只由出题配比调节）；
- **模型**：本地开源 Qwen2.5-7B-Instruct，Q4_K_M 量化，CPU 推理（llama.cpp），**模型只换不调**；
- **性质**：可行性闸门，不是性能评测，不是大样本统计。

### 6.2 四条对照的观测结果

**(ii) B 开环不降——最硬的一条。** 压假阳性桶中，A 闭环臂错误率 k0→k3 为 **1.00 → 1.00 → 0.75 → 0.50**，而 B 开环臂四轮**恒定 1.00**；配对差分 k2 为 +0.25、k3 为 +0.50。这排除了"只是把问题多问几遍自然变好"这一最常见的替代解释：同样的锚、唯一差别是有没有真闭环，结果一个降、一个纹丝不动。

**(i) A 随轮下降——方向成立，但有明确边界。** 中段信号强度的题有效；对错误率序列粗拟合得 **τ_fb ≈ 5.8 轮、R² = 0.99**，但**真正发生收敛的样本只有 n=2、且外推超过 k_max=3**，因此 τ_fb **仅有数量级意义、不能当定值**，置信区间要留给后续 M1。最贴近噪声地板的两题（z=0.53 / 0.18）四轮反馈都压不下去（见 §7.3 失效条件 5）。

**(iii) C 错锚反升——正锚纠错与错锚带偏是"同一枚杠杆的两面"。** "信错锚率"随信号由强到弱单调：clear 0 / fuzzy_stuck 0 / fuzzy_present 0.5 / fuzzy_absent 0.5 / below 1.0。模型越确定，对错锚越免疫；模型越没把握，越容易被（错误的）确定性锚带走。这与 A 臂"正锚也只在弱信号区把错误压下"恰好对称，凝出一条候选命题——

> **证据杠杆单调命题【E0】**：确定性锚点对模型结论的改变量，是模型自身不确定度的单调增函数。强信号区正锚错锚都几乎撼不动它；弱信号区正锚能纠错、错锚能带偏。它同时是 C3"按需唤醒、别在强信号区浪费回验"的理论依据。此命题待 M1 用更大样本检验其单调形状与拐点。

**(iv) D 纯创造无增益——边界成立。** 10 道无物理锚的题模型常数报 present，其中 4 个应为 absent 的全错、零区分度——即在"根本不该有锚作用"的地方，确实没有凭空产生降错增益，机制没有越界。

### 6.3 M0 结论：机制可行性通过预注册闸门（GO），但请严格限定读法

综合四对照，M0 判定**通过预注册闸门（下文简称 GO，其唯一含义是"机制方向成立、值得换更强模型复现"，并非性能达标）**。它**不是**：性能达标（准确率/延迟未评测）、不是定理已证（H7.3/H7.4 的经验有效性仍是工作假说）、不可外推到 7B 之外或窄任务之外。严格适用域写全就是：**系统失稳窄任务 × 中心化 z 证据锚 × Qwen2.5-7B Q4 × CPU**。

### 6.4 复现实验 M1：四个开源模型上的跨基座结果（证据档【E1】，请连同三条边界读）

M0 之后最自然的反问是：**这到底是 Qwen2.5-7B 这一个模型的偶然，还是机制本身在不同基座上都成立？** M1 用"冻结题集 + 冻结判据、只换模型"回答它。

**设置。** 采用一套冻结题集（24 题，按中心化 z 分 clear/fuzzy/below 三箱，真值与难度在实验前冻结）与一份冻结判据脚本，全程不改；换四个本地开源模型全量跑同一组四对照，A/B 臂每题独立重复 3 次，τ_fb 用固定种子 bootstrap 1000 次给出 95% 置信区间；模型只换不调，量化与推理后端统一记录，每档结果均由冻结脚本与一份独立复算脚本两路核对。

**结果一：闭环降、开环不降，在四个模型上重复出现。**

| 模型（量化，题面口径） | A 闭环错误率 k0/k1/k2/k3 | B 开环（四轮恒定） | 末轮配对差 B−A | τ_fb 中位 [95% CI]（轮） |
|---|---|---|---|---|
| Qwen3-14B（Q3，v3 正式口径） | 0.417/0.083/0.083/**0.000** | 0.417 | +0.417 | **2.60 [1.52, 7.83]** |
| Qwen3-VL-8B（Q4，v1 历史口径） | 0.522/0.217/0.217/**0.000** | 0.500 | +0.500 | **4.37 [1.87, 29.96]** |
| Qwen2.5-7B（Q4，v1 历史口径） | 0.500/0.500/0.375/**0.250** | 0.500 | +0.250 | **8.28 [3.86, 23.17]** |
| gemma-3-12B（Q4，v3 正式口径） | 0.458/0.417/0.375/**0.000** | 0.458 | +0.458 | **17.93 [6.81, 53.98]** |

四条预埋对照在 M1 的表现：(i) **A 闭环逐轮非增**，8B/14B/gemma 末轮归零，最弱的 7B 也从 0.500 降到 0.250；(iv) **B 开环四档全程恒定、轮间"错→对"反升率全部为 0**——这仍是最硬的一条，跨四个模型排除了"多问几遍自己变好"；(iii) **C 错锚在最弱箱 below 上四档全部被带反（0/6 答对）**，在强信号箱 clear 上则呈清晰能力分层（Qwen 同族 6/6 抗住、gemma 0/6 盲从、14B 居中 1/6），§6.2 的证据杠杆单调命题由此获得跨族形态；(ii) **D 无锚四档分布逐箱完全相同**，无反馈即无纠错。τ_fb 四档点估均为有限正、bootstrap 95% 置信区间下界均严格大于 0（最宽的 gemma [6.81, 53.98] 仍为正）。

**结果二（提示性规律，非强结论）：反馈收敛快慢与"判据可覆写性"相关，而非简单随参数量。** τ_fb 中位 14B(2.60) < 8B(4.37) < 7B(8.28) < gemma-12B(17.93)，参数最大的 gemma 反而最慢。候选解释是：反馈能否快速生效，取决于基座是否容易让"确定性判据"覆写自身先验、以及指令与结构化填写是否一致——这反向印证 §3.1 的分工（算 z、归一、选模必须由 System-1 做绝）。**但它目前只是提示性规律**，理由见边界①。

**三条必须连同结果一起读的边界（预注册时钉死，不得只报喜）：**

1. **口径混杂，τ_fb 只作数量级、不作精确排名。** 7B/8B 用 v1 历史题面（让模型自己算 z），gemma/14B 用 v3 正式题面（点名主带模、direction 置首、六个字段由程序回填）；跨口径只支持"有限正、有快有慢"的单调定性，"可覆写性而非参数量"须等 v3 统一口径复现后才能升为强结论。
2. **M1 测的是"给定判据后的可覆写性"，不是"模型自主显著性判断"。** 题面已把 z/b/ε_c 算好给模型，验证的是 H7.3 的一个特定实现形态；不给 z、只给原始谱让模型自主判显著更难，已另设相应题集作为后续检验，不得把 M1 外推成"模型已会自主做谱判断"。
3. **d_fb 的指数形状未被严格分辨。** k_max=4、每档仅 3–4 个拟合点、k1/k2 普遍是平台，τ_fb 只报数量级；d_fb 与物理弛豫的数学同构是结构命题【T】，但"反馈是否真等效正定耗散、残余错误是否真按指数收敛"仍是经验命题【E1】，不能用同构代替经验证明（P43 §4.2）。此外任务为二值窄任务、N=24、置信区间仅跨题且偏宽，7B 末轮 0.250 未归零，**因此不能说"四档都完全收敛"，更不能说"机制已被证明普适"。**

**M1 小结。** 在"系统失稳窄任务 × 中心化 z 证据锚 × 本地开源模型"这个精确适用域内，机制通过了跨两个模型族、四个参数档的复现，H7.3 由【E0】升为【E1】"有经验支持命题"，对应理论命题也据此正式写入 IGT 论文 P43（卷六）；它二分掉了"只是 7B 天花板"这一替代解释，但离普适定理仍有明确距离，撤回条件（§7.5）始终保留。多模态复现（M2，**已通过预注册判据、但限于基线感知识别＋耦合准入层面，H9.1 仍【E2】**）、不预给 z 的自主判显著题集、隐状态机制验证（**取数通路已验证、谱估计待做**）是接下来的关联节点。

## 7. 边界与诚实声明（这部分和结果同等重要）

### 7.1 承诺范围：只对"事实型、且有公共可校验量"的输出背书

模型主张先分四类（ClaimForCheck.claim_type）：**FactCheckable（可事实校验）/ Value（价值）/ Intent（意图）/ PureCreation（纯创造）**。只有第一类且能投影到公共校验空间的才进回验；后三类直接标 **UNVERIFIABLE 放行**，不硬验。对外承诺的完整范围只有一句：

> **"事实型输出的可复算背书（recomputable endorsement of factual outputs）"**——从不承诺"消灭幻觉"，更不覆盖价值判断与创造性内容。

### 7.2 系统级显著性：逐模 5% ≠ 系统级 5%（方法学陷阱）

"任一通道出现增长模即判 present"是一个存在性聚合。若 N 个模各自按 α=0.05 判，则全负时系统至少冒出一个假增长模的家族错误率 FWER = 1−0.95^N：N=10 时已达 **40.1%**、N=20 时 **64.2%**（可由公式直接验算）。因此必须在**系统级 present 输出层**校准到约 5%（或逐模 Bonferroni / BH-FDR），金标准还须覆盖非平稳/慢漂移工况。这是把"看起来灵敏"修成"统计上诚实"的必要一步。

### 7.3 六个失效条件（安全阀，实验前写死）

H7.3 是条件性不等式，下列任一触发即无增益甚至反增错：

1. **锚点本身错**：方向/数值错会注入错误约束——所以锚点只能是 core 纯函数可复算量、错误率远低于模型、带自检哈希；
2. **方向正交**：小脑算的维度与模型出错维度无关，投影为零，增益为零；
3. **回路不闭合（开环）**：只并列展示、不把打回灌进下一次生成（M0-B 臂已实证无效）；
4. **超出锚点定义域**：价值/意图/纯创造无物理锚，标 UNVERIFIABLE 放行（M0-D 臂已实证此处无增益）；
5. **证据低于可分辨阈**：锚点没错，但中心化 z 太小、弱到被噪声地板淹没，名义上有耗散、物理上不可分——M0 最贴地板两题（z=0.53/0.18）四轮压不下即此。它与条件 1 的区别是：**不是锚错，是锚太弱。**
6. **前端识别系统性读错/读反（引自 P43 §9.4.3）**：事实**存在**，但前端提取算子把它**系统性读错或读反**——锚一个被读错的坐标，收敛方向也错。**它与失效 5 正交**：失效 5 是信号弱到不可分，失效 6 是信号在、但**提取算子读错了**。**小脑检测到失效 6 应降级、不静默出错**——前端对不可信读数必须**显式拒绝准入**，不得静默放行。

### 7.4 机制层验证依赖"能取隐状态"的本地开源模型

H_hall（§2.2）这类**机制层**量必须读模型真实隐状态序列才能估计，因此只能用本地、可取隐状态的开源模型（**截至本文，逐 token 词嵌入与逐层隐状态张量的取数通路已验证可行，待完成的是 H_hall 的谱估计本身**）。**云端闭源黑盒取不到隐状态，只能跑行为层四对照**（看输入输出对错），无法做谱层面的机制验证。这也是本方案把"本地开源主力 + 云端仅作外部效度对照"定为主线的硬理由，而非偏好。

### 7.5 M1 复现通过闸门后：结论如何升档、又如何在未来被撤回

- **M1（复现，2026-09-09 通过预注册闸门，详见 §6.4）**：冻结同一套题与判据脚本，换四个开源本地模型（7B/8B/12B/14B、跨两个模型族）全量复现。(i)A 降、(iv)B 不降、(iii)C 弱区反升、(ii)D 无增益四条方向性复现，τ_fb 四档均有有限正解、95% 置信区间下界全为正，H7.3 由【E0】升为【E1】"有经验支持命题"，对应理论命题正式入卷六（P43）。
- **升档不等于封顶，撤回条件仍挂着**：若未来更大/更严的实验未通过闸门（NO-GO：开环也降 / 闭环不降 / 纯创造也降 / 杠杆不单调），或多模态 M2 出现"硬拼也被判融合"，则按 P43 §10.2 撤回强形式、降级为"特定模型的行为现象"，**不硬保**。下一阶段未决检验：不预给 z、测自主显著性判断的新题集；取真实隐状态检验 H_hall（对应 H7.2）；多模态 M2（**已于 2026-09-10 通过预注册判据，但限于基线感知识别＋耦合准入层面，H9.1 仍【E2】**）。
- **锚替代参数命题 H7.5【E0】（引自 P43 §7.8）**：System-2 所需参数规模是**锚定后残余探索熵** H_res=H0−I(A;T) 的单调增函数；同等事实能力下，耦合确定性锚的系统所需规模显著小于裸系统。**两条硬边界**：①不可约核心 N_floor>0（投影不出 F 的不锚）；②方向锚定于用户目标锥、幅度留健康涨落带（**锚定非等于、探索不灭**）。**标注【E0】：规模—熵标度曲线是工程验证、未完成**；对外用「**确定性骨架化、非取代**」表述。

> **一次云端 reasoning 模型的跨家族尝试（如实记录，未升档）**：我们也曾在一个云端 reasoning 型多模态模型（deepseek-v4-flash-vision）上重复跨家族复现，结果并不顺利：它把约 99.7% 的输出消耗在不外露的长推理上，导致结构化可验量契约在达到 max_tokens 前就被截断；而题中干净合成曲线图对它又过于简单，裸问即 24/24 满分，落在"看懂图"的能力天花板上，锚点增益无从体现（命题①在天花板上不可测）。仅在极少数完整返回的调用里看到符号方向与本地一致，但成功样本仅 n=3，不足以立通性。这一经历反过来印证：**增益的主证据来自语义/文本通道（M1【E1】＋跨呈现文本通道），视觉侧只承担基线感知识别，不对跨家族复现做未被支持的声称**；reasoning 模型"思考链吃掉输出预算"这一现象，也与 §8.2 的成本观察互为印证。

## 8. 工程落地中的两次"自我修正"（进行中，未计入 M0 证据）

为了让外部读者看到一个可证伪工程在真实数据上如何自我纠错，这里如实记录 M0 之后、尚未形成结论的两个进展，**均标"进行中"，不作为本文证据**。

### 8.1 真机数据第一次跑就"报错"，反而逼出一条理论补全

把输入从"合成失稳波形"换成真机采集的机器负载（CPU/内存等六维、受控拉高负载并标注注入时刻）后，增长谱在注入段判"无增长模"，与注入标签不符。深查发现：受控拉高负载造成的是**均值电平跃迁 + 方差体制切换**（例如 CPU 占用从 8.8% 阶跃到 64.9% 后维持新平台），**两段内部都稳定、没有指数增长过程**；而增长谱只对"段内增长模"敏感，对"段间工作点跳变"天然无模可检——这是算子在**正确地拒绝用错对象**，不是缺陷。

据此在理论上补出**两类正交异常的谱形态学（结构性命题【T】）**：**I 类＝段内动力学失稳**（增长模，走谱轨）；**II 类＝体制切换/工作点迁移**（变点，走新增的统计变点算子 C1-stat，先分段、段内才上谱）。外部受控阶跃只产生 II、不经过 I，这正是用 I 类算子去测 II 类注入必然"检不到"的原因。工程上随之确立"**先统计分段、段内才估谱；近恒定信号降轨到统计层、不硬出谱**"的顺序铁律，并把验证数据相应分为两型：合成失稳型（考谱轨）与真机体制切换型（考变点轨），分库验收、不得互冒。**该双子层（统计变点算子 C1-stat／谱算子 C1-spec）与"先分段、后估谱"的顺序已在 P43 正式成段【T，构造】；真机两类验证数据（失稳型／体制切换型）分库验收则仍是进行中的工程项。**

### 8.2 成本侧的一个工程观察

强推理模型默认携带很长的内部"思考链"，在这种结构化窄任务上相当浪费。一次工程对照中关闭思考链后，**单次 completion 平均 token 由约 5427 降到 314（约 17 倍）**，而最终判对率不变，代价仅是边界模糊题在第 0 轮更容易错、需要一轮反馈救回——闭环反馈恰好兜住。这与 §2.4 的图景一致：**"模型一次想对"和"模型粗判 + 确定性反馈逐轮收敛"是两条可替代路径，后者显著更省。** 须说明这是单次工程对照、非系统性结论，仅提示成本不是障碍。

## 9. 复现清单：别人如何检验我们是不是自说自话

1. **题与判据冻结**：出题集、中心化归箱阈值、k_max 实验前固定，实验中不改题、不调 ε_c 去凑错误率（防 Goodhart）；
2. **噪声地板客观估计**：ε_c 只由同窗长 bootstrap 零分布得到，分档查表、禁跨档挪用；真实无基线场景不可照搬合成标定表；
3. **系统级校准**：在 present 输出层把系统误报校准到约 5%，并报告逐模与系统级两级阈值；金标准覆盖非平稳/慢漂移；
4. **同时报 A、B 两臂各自轨迹与配对差分**，不能只报差分（否则开环基线被藏起来）；
5. **证据/裁决分层留痕**：证据层如实记录原始符号（哪怕为负），裁决层按中心化 z 判，两层不互相覆盖；
6. **mock 通过的臂，交付前至少用一题真模型冒烟**——本项目多个 bug（包括一次反馈文本用旧口径反向误导模型）只有真模型能暴露，mock 全绿不代表链路对；
7. **核心纯函数可复算、带哈希**：同一份输入任何时候重算结果一致；模型调用、网络、采集全部隔离在 core 之外。
8. **制品可得性**：核心纯函数（整个 igt_core）、24 题冻结题集、模型臂 harness、自包含闭环编排、判据脚本与原始实验记录已随开源仓库一并公开：

   - Gitee 镜像：https://gitee.com/zheng-sheng7/igt-physical-cerebellum

   符号口径与复现步骤见仓库根 CALIBRATION.md、experiment/run_closed_loop.py；M1 四模型原始轨迹见 experiment/results/。

## 10. 结语：不消灭幻觉，而是让一类错误变成"可收敛、可证伪、可复算"的工程对象

大模型的事实型错误过去常被当成一个"模型够不够聪明"的问题，于是解法被不断寄托在更大的参数、更多的知识、更巧的提示上。本案例给出另一条思路：**承认大模型在"事实方向"天然缺一个约束，然后用一个确定性、可复算、独立于模型的"物理小脑"补上这个约束，并把纠错做成真正闭合的反馈回路。**

首轮实验在一个刻意收窄的任务上看到了理论预言的完整图案——闭环才降、开环不降、弱区才被锚点撬动、无锚域不受影响、证据太弱则谁也救不了。它同时诚实地写明：这是条件性机制而非普适定理、样本极小、只覆盖事实型输出、机制层测量还需本地可取隐状态的模型，并且已经预先规定了"看到什么就撤回"。

我们认为，这种"**增益、无效、反作用都能在实验前被预言、在实验中被检验、在失败时被主动撤回**"的结构，比任何一个漂亮的准确率数字都更重要。它让"大模型会不会错"这件事，第一次有机会从修辞问题变成一个**有弛豫时间、有容差、有反馈轮数、有失效清单、可以持续工程化收敛**的对象。
